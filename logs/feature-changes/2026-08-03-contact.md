## Notable decisions

- **Wipe = transform-only "dome cap"** (half-ellipse `rounded-t-[50%_100%]` above the sheet, `scaleY 1→0.001` scrub, origin bottom) instead of border-radius/clip-path scrub — GPU-composited, no per-frame repaint. Dome is `aria-hidden` + `pointer-events-none` (overlays the clickable Articles rail while rising) and not rendered under reduced motion (static flat-top sheet).
- **`[data-invert]` CSS scope** re-points only the tokens that fail AA on `#e8e8e8`; components stay untouched (ChapterEyebrow fixed with zero code changes). `bg-accent` deliberately not remapped — the duotone wash is non-text. Section JSX uses `accent-deep` directly for its own small accent text.
- **Duotone = grayscale `Image` + `bg-accent mix-blend-multiply` overlay** in an `isolate` wrapper, not `ParallaxImage` (its clip reveal can't host a blend layer). Decorative reuse of the About portrait (`alt=""`).
- **Heading is the single word "Contact"** (video-faithful); the eyebrow `10 — Let's Talk` carries PLAN's verbal register. The reference's second blurb/image beat is dropped — the form band occupies that scroll beat.
- **Channels-only degradation is the default path**: without `VITE_EMAILJS_*` keys the form never renders and the contactChannels list spans the band. RHF `register`-only on `Box as="input"` (React 19 ref-as-prop); no shadcn form parts (their compat tokens alias the dark palette).
- **Statement availability framing** ("open to new opportunities") is not PRD copy — owner's explicit pick at the plan gate (2026-08-03), recorded in the data docblock; facts (role, location) are PRD §2.
- QA fixes applied same-pass: `overflow-x-clip` on the section root (130vw dome caused real horizontal pan), DOM order statement→socials so mobile reading/focus order matches visual (desktop composition kept via `lg:order-*`), contrast-comment correction (accent-deep on light is 5.2:1).
