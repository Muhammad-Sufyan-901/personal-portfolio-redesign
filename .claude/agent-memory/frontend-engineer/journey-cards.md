## Polish pass 2026-07-25 (on top of the gradient card below)

- **Card DOM is 3 nested boxes, and the split is load-bearing** (revised 2026-07-25 so the node sticks to the tilting card):
  `.journey-reveal` (scrub target, relative) › `.journey-card-tilt` (tilt target, `relative`, **never `overflow-hidden`**) › the visual card box (`group bg-ink rounded-card overflow-hidden` + halo shadow + padding).
  The connector node is a child of the TILT wrapper, so it rides the 3D rotation; it can't live in the card box (that box clips a half-outside node) and mustn't go back to being the wrapper's sibling (then it floats while the card tilts). **If the tilt wrapper ever gains an overflow class, the node gets clipped again.** Absolutely-positioned children don't size a parent, so the wrapper's rect still equals the card's and the tilt pointer maths is untouched. The halo stays a box-shadow on the inner card box — shadows escape their own clip, and it still rides the tilt as a descendant of the wrapper.
- **Connector node** marks where the drawn line meets each card. **Its y needs no measurement**: the row is `flex items-center` AND is the element the ResizeObserver measures for the tip, so `top-1/2` IS the tip's y (verified at rest: dot centre x == card edge x, dot centre y == card mid y, both sides). Edge follows side (`side==="right"` → `left-0 -translate-x-1/2`, else mirrored). `hidden md:block` — below md the card is `w-full` while tips stay at 0.4w/0.6w.
- **`ring-ink` on the dot core is load-bearing**: dot and stroke are both ember, so without an ink gap the node dissolves into the line it marks. Applies to anything ember placed on the ember thread.
- **CSS-loop motion needs no `usePrefersReducedMotion`** — Tailwind's `motion-safe:` variant compiles to `@media (prefers-reduced-motion: no-preference)`, which IS the whole fallback (verified in compiled CSS). Reach for the hook only when GSAP/JS is involved.
- **Size a heading off another token**: `text-[length:calc(var(--text-body)*1.5)]` (card title, owner ask "1.5× the description"). The `length:` hint stops Tailwind parsing the `calc()` as a color, and `leading-tight` is REQUIRED — an arbitrary font-size doesn't carry the token's `--text-*--line-height` companion. Prefer this over a new `--text-*` token (which would also need registering in `src/lib/utils.ts`'s twMerge groups).
- **04 Projects and 08 Journey share ONE badge language** (completed 2026-07-25): same `TECH_ICONS` map (`utils/tech-icons.ts`) AND the same light-glass pill — `border-paper/15 bg-paper/10 text-paper-bright font-mono text-meta flex items-center gap-1.5 rounded-full border px-2.5 py-0.5 backdrop-blur-md` + `{TechIcon && <TechIcon aria-hidden className="size-3" />}`. Journey's older `border-line`/`text-muted` outline pill is retired. Add labels to `TECH_ICONS`, never a second lookup map; unmapped labels (`Blade`, `Docs`) fall through to text-only by design.
- Bullets are `marker:text-accent` (was `text-faint`, near-invisible on ink). `line.strokeWidth` re-weighted to `clamp(1rem, 3.5vw, 4rem)`.

## Reusable patterns proven here

- **Gradient border that respects `border-radius`** (2026-07-24, first mask usage in `src/`): a `border-color` can't be a gradient and `border-image` ignores rounding (it draws a square frame), so use an `absolute inset-0` element carrying ONLY a border, faded with `mask-image` (+ `WebkitMaskImage` for Safari < 15.4). No `mask-composite` punch-out is needed because there's no background to subtract, and it degrades to an even rim instead of a filled block. **Straight bars can never do this job**: inside a `rounded-* overflow-hidden` box they're clipped exactly where the curve starts, leaving the corners bare — that bug is what this ring fixed. If the element should be the box's only border, drop the box's own `border` so padding box == border box and the radii match exactly.
- **Unclipped-wrapper aura split** (bolder pass 2026-07-22) for any card needing a *gradient-shaped* glow that escapes its own clip: outer `journey-reveal` wrapper stays UNCLIPPED and is the GSAP scrub target; an `aria-hidden` aura layer (`color-mix` radial, negative insets) is its FIRST child so DOM order alone makes the card's opaque bg occlude it (no z-index/blur); the clipped card is the SECOND child. Currently no live instance (the 2026-07-24 halo uses box-shadow instead), but reuse this shape when a halo needs multi-hue/gradient geometry a shadow can't do.
- **Per-card tilt listeners** (2026-07-23): `gsap.quickTo` on `rotationX/rotationY/y` per card (`JOURNEY.tilt`), targeting the INNER `.journey-card-tilt`, never `.journey-reveal` (the scroll-scrub target) — hover and scrub can never fight one property. Reuse for any grid of independently-tiltable cards (Projects' section-level-listener variant only fits a single shared panel).
- **Conveyor reveal**: per-row `gsap.from` with NUMERIC `scrub` (1.2) = GSAP-native damped, reversible reveal. Scrubbed ±120px x-nudges expand overflow → `overflow-x-clip` on the section (clip, NOT hidden) is load-bearing.
- **Measured zigzag line**: `buildZigzagPath(w, h, tips, opts)` in `utils/path.ts` — real card centers via the line layer's ResizeObserver (`[data-side]` on each `<li>`; only `.y`/`.dataset.side` read — reveals translate X only, so y is stable pre-reveal); pixel-space `d` + 1:1 viewBox; sloped entry mirrors the exit-sweep control-point grammar, fed by `line.entryRunway` (40svh) before the `<ul>`, exit through `line.finaleRunway`. Reuse for any line that must track viewport-dependent content instead of hand-authoring a `d`.
